How to Resize an Image to 200KB in 4 Steps

  1. Choose your photo in the tool above (or several at once). iPhone HEIC photos and PNG screenshots are fine; the result is always a real JPG.
  2. Check the limit: the tool is set to 200 KB. If the form also gives a minimum, such as “20 to 200 KB”, type it in the second box so the file is not too small either.
  3. Set the dimensions only if the form gives them. Leave “Keep shape” selected otherwise: the tool shrinks the photo just enough to stay sharp. OCI and US visa photos must be square: choose pixels and 600 × 600.
  4. Download the JPG (or all of them as a .zip) and upload it. The result line shows the exact KB, the size in pixels and the JPEG quality it used.

Photo vs Document at 200 KB

A photo of a person compresses easily. A photo of a document (marksheet, certificate, passbook) has sharp text and paper texture, which makes the file bigger. For documents, crop to the edges of the paper and tick “Black and white” if the form allows it: the paper turns white and the text stays crisp. If the form asks for a PDF rather than a JPG, use the [[post:articles/compress-pdf-to-200kb|compress PDF to 200 KB tool]].

How the Tool Picks the Size

A JPEG's file size depends on two things: how many pixels it has and how strongly it is compressed (the “quality” setting). Most compressors only lower the quality, which is why their 20 KB results look blocky. This tool searches for the highest quality that fits and, if that would fall below about 60%, makes the photo slightly smaller in pixels instead, because a smaller sharp photo looks far better on a form than a large blurry one. It also writes the resolution (dpi) into the file, which some government portals check, and counts 1 KB as 1,000 bytes so the file passes whichever way the portal measures.

What is a 200 KB photo in pixels?

Is 200 KB the same as 0.2 MB?
