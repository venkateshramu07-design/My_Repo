1 MB, 1,000 KB or 1,024 KB?

Portals do not always say which they mean. Windows counts 1 MB as 1,024 KB; phones, Macs and many web servers count 1,000 KB. The tool keeps every file under 1,000,000 bytes, so a PDF it makes for a “1 MB” limit passes either way. If your file shows as 0.98 MB on one device and 1.02 MB on another, that is why.

What Happens to My PDF When It Is Compressed?

The tool first tries a lossless squeeze: it rebuilds the PDF with compressed internal structures, which keeps text selectable and changes nothing you can see. That is often enough for PDFs made on a computer. If the file is still too big, usually because it is a scan or contains photos, it redraws every page as an image: in colour as a JPEG, using the highest resolution and quality that fit, or as a pure black-and-white image, which is how fax and document scanners store text and is often ten times smaller than colour. In Auto mode the tool keeps colour when it stays clear and uses black and white when colour pages would be blurry. The page size stays the same (A4 stays A4), it prints the same, and the preview shows the first pages so you can check every line before you download. Nothing is uploaded: the PDF is read and rebuilt inside your browser by the open-source PDF.js and pdf-lib libraries.

How do I reduce a PDF from 10 MB to 1 MB?
